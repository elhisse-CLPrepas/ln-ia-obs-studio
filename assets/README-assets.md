# Assets LN-IA OBS

Ce dossier contient les éléments visuels utilises dans OBS Studio.

Éléments recommandés :

- `logo-LN-IA.png` : logo LN-IA officiel ;
- `fond-attente.png` : fond sobre pour la scène pause ;
- miniature de replay au format 16:9 ;
- images temporaires pour les formations.

Conseils :

- garder des fichiers légers ;
- utiliser des noms courts et explicites ;
- éviter les visuels confidentiels ;
- conserver une version source si une miniature est modifiee.
