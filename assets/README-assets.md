# Assets LN-IA OBS

Ce dossier contient les elements visuels utilises dans OBS Studio.

Elements recommandes :

- `logo-ln-ia.png` : logo LN-IA ;
- `fond-attente.png` : fond sobre pour la scene pause ;
- miniature de replay au format 16:9 ;
- images temporaires pour les formations.

Conseils :

- garder des fichiers legers ;
- utiliser des noms courts et explicites ;
- eviter les visuels confidentiels ;
- conserver une version source si une miniature est modifiee.
