# Guide pour enregistrer une vidéo sur PC

Ce guide sert pendant une session d’enregistrement LN-IA avec OBS Studio.

## 1. Ouvrir OBS

1. Brancher le microphone et la webcam si nécessaire.
2. Ouvrir OBS Studio.
3. Vérifier que les sources sont visibles.
4. Lire la checklist avant enregistrement.

## 2. Choisir la scène

Sélectionner la scène adaptée :

- `Écran + Webcam` pour une démonstration générale ;
- `Plein écran présentation` pour un support de cours ;
- `VS Code + Webcam` pour une formation technique ;
- `Pause / écran d’attente` pour une transition.

## 3. Lancer l’enregistrement

1. Cliquer sur `Démarrer l’enregistrement`.
2. Attendre deux secondes.
3. Commencer l’introduction.
4. Parler clairement et garder un rythme calme.

## 4. Arrêter l’enregistrement

1. Terminer la conclusion.
2. Attendre deux secondes.
3. Cliquer sur `Arrêter l’enregistrement`.
4. Patienter pendant l'écriture du fichier.

## 5. Retrouver le fichier vidéo

1. Aller dans le dossier configuré dans OBS.
2. Par défaut pour ce kit : `recordings/`.
3. Vérifier que le fichier s’ouvre correctement.

## 6. Nommer le fichier

Utiliser un nom clair :

```text
AAAA-MM-JJ_LN-IA_theme-court_v01.mp4
```

Exemple :

```text
2026-05-17_LN-IA_initiation-obs_v01.mp4
```

## 7. Archiver le replay

1. Conserver la vidéo brute dans `recordings/`.
2. Placer la version finale dans `exports/`.
3. Ajouter une description courte.
4. Préparer le lien de partage.
