# Guide pour enregistrer une video sur PC

Ce guide sert pendant une session d'enregistrement LN-IA avec OBS Studio.

## 1. Ouvrir OBS

1. Brancher le microphone et la webcam si necessaire.
2. Ouvrir OBS Studio.
3. Verifier que les sources sont visibles.
4. Lire la checklist avant enregistrement.

## 2. Choisir la scene

Selectionner la scene adaptee :

- `Ecran + Webcam` pour une demonstration generale ;
- `Plein ecran presentation` pour un support de cours ;
- `VS Code + Webcam` pour une formation technique ;
- `Pause / ecran d'attente` pour une transition.

## 3. Lancer l'enregistrement

1. Cliquer sur `Demarrer l'enregistrement`.
2. Attendre deux secondes.
3. Commencer l'introduction.
4. Parler clairement et garder un rythme calme.

## 4. Arreter l'enregistrement

1. Terminer la conclusion.
2. Attendre deux secondes.
3. Cliquer sur `Arreter l'enregistrement`.
4. Patienter pendant l'ecriture du fichier.

## 5. Retrouver le fichier video

1. Aller dans le dossier configure dans OBS.
2. Par defaut pour ce kit : `recordings/`.
3. Verifier que le fichier s'ouvre correctement.

## 6. Nommer le fichier

Utiliser un nom clair :

```text
AAAA-MM-JJ_LN-IA_theme-court_v01.mp4
```

Exemple :

```text
2026-05-17_LN-IA_initiation-obs_v01.mp4
```

## 7. Archiver le replay

1. Conserver la video brute dans `recordings/`.
2. Placer la version finale dans `exports/`.
3. Ajouter une description courte.
4. Preparer le lien de partage.
