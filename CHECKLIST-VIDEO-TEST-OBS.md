# Checklist vidéo test OBS

Cette checklist valide qu'une vidéo test OBS contient les éléments essentiels avant de lancer une vraie formation LN-IA.

## Fichier attendu

- Nom : `test-obs-ln-ia-v0.1.0.mp4`
- Durée cible : 2 minutes
- Dossier : `recordings/`

## Introduction orale

```text
Bienvenue dans l’atelier OBS LN-IA.
Objectif : enregistrer une vidéo pédagogique claire avec écran, voix et présence humaine.
```

## Éléments à vérifier

- [ ] 1. Votre écran PC est visible.
- [ ] 2. Votre webcam ou photo en direct est visible.
- [ ] 3. Votre micro est testé et audible.
- [ ] 4. Le logo LN-IA est affiché.
- [ ] 5. Une courte introduction orale est enregistrée.
- [ ] 6. Le fichier vidéo `test-obs-ln-ia-v0.1.0.mp4` est exporté.

## Validation rapide

Après le test, ouvrir le fichier vidéo et vérifier :

- le son ;
- la lisibilité de l’écran ;
- le cadrage webcam ou photo ;
- la présence du logo ;
- le nom du fichier ;
- le dossier de sortie.

Nom conseillé :

```text
test-obs-ln-ia-v0.1.0.mp4
```
