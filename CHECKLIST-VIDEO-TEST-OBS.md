# Checklist video test OBS

Cette checklist valide qu'une video test OBS contient les elements essentiels avant de lancer une vraie formation LN-IA.

## Fichier attendu

- Nom : `test-obs-ln-ia-v0.1.0.mp4`
- Duree cible : 2 minutes
- Dossier : `recordings/`

## Introduction orale

```text
Bienvenue dans l'atelier OBS LN-IA.
Objectif : enregistrer une video pedagogique claire avec ecran, voix et presence humaine.
```

## Elements a verifier

- [ ] 1. Votre ecran PC est visible.
- [ ] 2. Votre webcam ou photo en direct est visible.
- [ ] 3. Votre micro est teste et audible.
- [ ] 4. Le logo LN-IA est affiche.
- [ ] 5. Une courte introduction orale est enregistree.
- [ ] 6. Le fichier video `test-obs-ln-ia-v0.1.0.mp4` est exporte.

## Validation rapide

Apres le test, ouvrir le fichier video et verifier :

- le son ;
- la lisibilite de l'ecran ;
- le cadrage webcam ou photo ;
- la presence du logo ;
- le nom du fichier ;
- le dossier de sortie.

Nom conseille :

```text
test-obs-ln-ia-v0.1.0.mp4
```
